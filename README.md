# BrainDump

An AI-powered task manager with a brain dump feature. Capture tasks via natural language, and dump random thoughts to search later.

## Structure

```
apps/
  app/             # React Native (Expo) — iOS, Android, web

  (to be built)
```

## Getting Started

```bash
bun install
cd apps/app
bun start
```
